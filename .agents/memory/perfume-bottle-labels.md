name: Perfume bottle labels
description: Product requirement for the Badshah perfume catalog's shared bottle image and dynamic name labels.
---

Use the user-provided bottle image as the standard product bottle. Render each perfume name as a responsive label that scales to fit, and make that image the default for new products added through the admin panel. Keep custom image uploads available as overrides.

**Why:** The user wants product bottles to show their own names automatically, including products added later from admin.

**How to apply:** Keep the bottle template and name overlay shared across product imagery; new product creation should default to the template and show a live preview.
